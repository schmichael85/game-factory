# Game Factory

Small educational games that run offline in any browser. Each game is a single HTML file. To play, download it and double-click it.

## Games

| Game | Folder | Subject | Language |
|---|---|---|---|
| Block World – Geometry (עולם הקוביות) | `geometry/` | 5th-grade geometry: angles, shapes & triangles, perimeter & area | Hebrew |

### Block World – Geometry
Four modes: mining quest (3 worlds × 6 levels), 60-second race, block builder (area/perimeter missions), and angle cannon.
The player types their name on first launch. Progress stays only on the computer (browser localStorage). Nothing is sent anywhere.
There's a parent screen behind a multiplication question. It shows time per mode, success by topic, and how the player rated each mode.
