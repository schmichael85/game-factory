# Game Factory

Small educational games that run in any browser (Windows, macOS, Chromebook, tablets). Play online: https://schmichael85.github.io/game-factory/

They also run offline. Each game is a single HTML file. To play, download it and double-click it.

## Games

| Game | Folder | Subject | Language |
|---|---|---|---|
| Block World – Geometry (עולם הקוביות) | `geometry/` | 5th-grade geometry: angles, shapes & triangles, perimeter & area | Hebrew |

### Block World – Geometry
Four modes: mining quest (3 worlds × 6 levels), 60-second race, block builder (area/perimeter missions), and angle cannon.
Several kids can share one device. A "Who's playing?" screen (👤 button) keeps a separate profile for each player, with its own stars and parent report. Progress stays only on that device (browser localStorage). Nothing is sent anywhere.
There's a parent screen behind a multiplication question. It shows time per mode, success by topic, and how the player rated each mode.
